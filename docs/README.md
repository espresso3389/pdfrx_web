# Documentation

Start with the README for the package you plan to install. These documents hold
the longer implementation, customization, protocol, and maintenance material
that would otherwise obscure each package's quick start.

## Package guides

- [`@pdfrx/engine`](ENGINE-GUIDE.md): browser and server runtimes, rendering,
  extraction, editing, events, encoding, and worker configuration.
- [`@pdfrx/viewer`](VIEWER-GUIDE.md): custom-element and class integration,
  interaction, layout, annotations, overlays, and viewer options.
- [`@pdfrx/react`](REACT-GUIDE.md): all-in-one, composed, and headless
  integration; editing, save/history behavior, localization, and theming.
- [`@pdfrx/colab`](COLAB-GUIDE.md): relay setup, authentication transport,
  synchronization, lower-level clients, adapters, export, and conflict policy.
- [Customizing `PdfrxViewerApp`](REACT-VIEWER-APP-CUSTOMIZATION.md):
  application-controlled open, page, and export operations.

## Design and specifications

- [Architecture](ARCHITECTURE.md): package layering, worker protocol,
  coordinate conventions, forms, annotations, and known limitations.
- [Collaboration design](COLLABORATION.md): reusable local mutation and
  collaboration boundaries.
- [Collaboration relay protocol](COLLABORATION-PROTOCOL.md): authoritative wire
  and source-storage contract.
- [Missing-font fallback](FONT-FALLBACK.md): font selection, customization, and
  licensing.
- [Text, language, and emoji appearance](TEXT-APPEARANCE.md): Unicode and
  grapheme handling, mixed-script FreeText, cross-runtime emoji fallback,
  caching, offline assets, and custom renderers.

## Generated API documentation

The public symbol reference is generated by TypeDoc and published at
[espresso3389.github.io/pdfrx_web](https://espresso3389.github.io/pdfrx_web/).
Package READMEs and guides should link directly to symbol pages when discussing
specific APIs.
